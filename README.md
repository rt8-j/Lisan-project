# لِسان (Lisan) | نظام الاتصال الطبي الإسعافي متعدد اللغات


## نبذة عن المشروع (Overview)
يواجه الطاقم الطبي في أقسام الطوارئ خلال موسم الحج والفعاليات الكبرى تحدياً كبيراً يتمثل في حاجز اللغة بين الممارس الصحي والحاج غير الناطق باللغة العربية أو الإنجليزية. 
تطبيق "لِسان" هو منصة طبية إسعافية ذكية تعمل بدون إنترنت (Offline-first PWA)، مصممة لمساعدة الأطباء في أخذ التاريخ المرضي الإسعافي للمصابين بدقة وسرعة عبر حزم لغات تفاعلية ووحدات ترجمة متقدمة.

---

## الميزات الرئيسية (Key Features)
* دعم العمل بدون إنترنت (Offline-Capable): مخصص خصيصاً للعمل في مناطق الضغط الشبكي الضعيف أو انقطاع الإنترنت باستخدام تقنيات الـ PWA.
* حزم لغات قابلة للتحميل: يوفر حزم لغات متعددة وموجهة خصيصاً لجوانب الطوارئ الطبية.
* وضعا الاستخدام: 
  * وضع الطوارئ (Emergency Mode): للوصول السريع للأعراض الحرجة والأسئلة الحيوية بنقرات معدودة.
  * الحالات العادية (Standard Mode): لأخذ التاريخ المرضي الشامل.
* واجهات مستخدم احترافية: تم تصميم واجهات تجربة المستخدم (UX/UI) بعناية فائقة وتغطية كاملة لسيناريوهات الاستخدام السريري.

---

## التقنيات المستخدمة (Tech Stack)
* Frontend: HTML5, Modern CSS, JavaScript (PWA Architecture)
* UI/UX Design: Figma (8 تفاعلات والشاشات الأساسية المخصصة لتدفق عمل الطبيب)
* Deployment & Version Control: Git & GitHub

---

## واجهات النظام (Screens & Architecture)
يعتمد التطبيق على سيناريو دقيق يبدأ بتحديد لغة المريض، ثم اختيار نوع الشكوى الطبية (تنفسية، قلبية، إصابات، وغيرها)، وصولاً إلى ملخص تقرير الحالة للطبيب باللغة العربية.
